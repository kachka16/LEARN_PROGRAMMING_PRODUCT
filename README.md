# Навчальний мобільний застосунок для вивчення C++ (Unity)

## Мобільний застосунок, розроблений на базі рушія Unity для інтерактивного вивчення мови програмування C++. Продукт поєднує теоретичні матеріали та практичні завдання у форматі коротких уроків і вправ безпосередньо на мобільному пристрої.
